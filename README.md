# Automatización de Virtualización de Nodos Lógicos

Este proyecto automatiza el despliegue de máquinas virtuales (VMs) en OpenStack a partir de archivos `.xml` de tipo SCL (Substation Configuration Language). Todo el proceso está integrado y simplificado mediante `make`, pero hay que añadirle la información necesarias para cada prueba específica que se quiera hacer (archivos SCL y añadir terraform.tfvars para poder acceder a OpenStack (creación de VM) como a Artifactory (almacén de imágenes docker)).

---

## 📂 Ubicación de los archivos `.xml`

Para que los archivos `.xml` de tipo SCL sean detectados y procesados correctamente durante la automatización, deben colocarse dentro de la carpeta:

```
creando_nodos/archivos_xml/
```

Solo los archivos en esta ubicación serán considerados para el proceso de virtualización.

---

## 🔐 Configuración de credenciales (OpenStack + Artifactory)

Para poder descargar las imágenes necesarias desde Artifactory durante el despliegue, es necesario proporcionar tus **credenciales personales**.

Estas credenciales deben añadirse en el archivo:

```
terraform_artifactory/terraform.tfvars
```

El archivo `terraform.tfvars` debe tener el siguiente contenido:

```hcl
# Credenciales de OpenStack
auth_url         = "https://cloud.tecnalia.dev:13000/v3"
region           = "regionOne"

user_name        = "user@tecnalia.com"
user_domain_name = "tri.lan"

project_name      = "virtualizacióndenodoslógicos"
project_domain_id = "3e6dcdec8ad44563a8334675306bc571"

# Parámetros de la instancia
instance_name = "rhel-docker-host"
image_name    = "ubuntu-22.04-server-cloudimg-amd64"

#flavor_name = "gpu2_2"  # Alternativa para uso con GPU

# Certificado (opcional)
```

## 🧨 Destruir toda la infraestructura

Debido a limitaciones de espacio en OpenStack, **es necesario liberar los recursos anteriores antes de realizar un nuevo despliegue**. Esto incluye:

- Máquinas virtuales anteriores.
- Carpetas generadas por Terraform (por ejemplo, `IED*`).
- Archivos `docker-compose-<número>.yml`.

Para eliminar todos estos recursos de forma automática, ejecuta:

```bash
./destroy.sh
```

Este script se encargará de:

- Ejecutar `terraform destroy` en las carpetas `terraform/` y `terraform_artifactory/`.
- Borrar todas las carpetas `IED*`.
- Eliminar todos los archivos `docker-compose-<número>.yml`.

---

##  Despliegue

Una vez configurado todo, lanza el despliegue con:

```bash
make
```

Se te pedirá que respondas a algunas preguntas para personalizar el entorno.  
Luego, el sistema procesará automáticamente los archivos `.xml` y desplegará las VMs correspondientes.
